# 本地知识库

这个目录放**人工整理**的领域知识，供学姐检索时使用。与 RAGFlow 那套（计算机教材）互为补充。

## 目录约定

```
knowledge_base/
├── README.md          ← 本文件
├── _模板.md            ← 新建知识文件的模板，下划线开头的文件会被忽略
├── 怪猎/
├── 百度飞桨/
├── 明日方舟/
└── 永劫无间/
```

- **一个子目录 = 一个领域**。新增领域直接建目录即可，不用改代码。
- 子目录里的 `.md` 文件就是这个领域的知识。
- **以下划线 `_` 开头的文件、以及 `README.md` 会被检索忽略**，可以放心写备注。

## 文件写法

每个 md 用 YAML 头注明元信息，正文随便写（表格、列表、链接都行）：

```markdown
---
领域: 怪猎
类型: 知识 | 站点索引 | 术语表
来源: 人工整理 / 链接出处
更新: 2026-10-13
---

# 标题

正文……
```

## 重要提醒

**不要把不确定的内容写进来。** 这些文字会直接作为"证据"喂给模型，
写错一条比不写更糟——模型会把错误当事实复述出去。

- 数值、掉落、技能倍率这类**务必注明出处和版本**，游戏一更新就会过期。
- 拿不准的宁可只留站点链接，让检索走联网那条路。
- 标注了版本的内容，记得在版本更新后回来改。

## 关于站点链接

`百科站点.md` 里存的是各领域的权威站点。它们的作用是：

1. 模型可以顺着链接去查证；
2. 联网检索命中这些域名时，可信度更高。

**域名如已失效或被墙，请直接删掉那一行。**
