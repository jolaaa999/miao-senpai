## 两条学习主线

我们社团的学习会存在两条主线，针对两种方向目标不同的人群，但是两条主线也会存在交叉。

### 面向想「保研」的同学

- 我们社团的教学存在「深度学习」的知识，你们可以理解为目前本科计算机科研的基础
- 我们这边认识很多老师，你们有了明确的方向后可以向你们推荐

### 面向想「就业」的同学

- 我们的社团也会指明一些紧跟当前时代的信息，主要以 Agent（智能体）为主
- 有关有哪些 agent、如何更好地使用 agent
- 再深一层：有 agent 的底层逻辑，以及如何构建、开发一个 agent
