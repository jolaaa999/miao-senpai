# 百度飞桨俱乐部 · 招新与考核

## 报名流程

想要加入百度飞桨的小朋友，需要在下面这个网站中跟随 README 文件的流程进行报名噢，
后续我们将通过发送的方式告诉大家正式成为百度飞桨俱乐部的一员 (OvO)。

- 报名仓库：https://github.com/wustLABA/wustlaba-recruit

## 考核一：试卷

百团大战之后我们会设立一张试卷，大家写试卷，有我们的学长学姐来看看。

- 不用担心试卷很难、没有基础
- 试卷的内容有很多主观题，讲的是你们以后的规划、理想、对目前时代的看法这些
- **最后的筛选并不是按照试卷的分数进行筛选的**

## 考核二：用 AI 做一个属于自己的小东西

需要了解 GitHub、Git，然后使用 AI（最好是 agent）做一个属于自己的小东西。

可做的方向举例：

- 个人博客
- 小游戏
- 写小说的流水线
- 通过 AI 做的 3D 模型
- 各种用于方便自己生活、或者满足自己爱好的东西（编程生万物）

交付方式：

- 上传到属于你们自己的 GitHub 上面
- 填表到共享 Excel 表格里面，大家都可以看到，相互鉴赏打分
- **GitHub 的项目记得开 issue**
