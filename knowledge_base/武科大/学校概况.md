# 武科大 · 学校概况

> 武汉科技大学（WUST）是湖北省人民政府与教育部共建的地方高校，**不是**国家级"双一流"；在武汉市有青山、黄家湖、洪山三个校区。

## 一、办学层次与主管部门

- **办学性质**：公办全日制普通高校。
- **学位授予**：具有学士、硕士、博士学位授予权，设有博士后科研流动站。
  - 出处：学校官网《武汉科技大学2026年全日制普通本科招生章程》第三条，<https://zs.wust.edu.cn/info/1891/15171.htm>（2026-10-13 实测打开）。
- **主管部门 / 共建方式**：湖北省人民政府和教育部共建；1998 年成为第一批"中央与地方共建，以湖北省人民政府管理为主"的划转院校。
  - 出处：《学校简介》，<https://www.wust.edu.cn/xxgk.htm> 与 <https://xxgk.wust.edu.cn/info/1071/69992.htm>。
- **学校自我定位**（两个官方页面的措辞不一致，原文照录，不做取舍）：
  - 《学校简介》："湖北省人民政府和教育部共建的地方高水平大学、湖北省'国内一流大学建设高校'"。
  - 《2026年全日制普通本科招生章程》："湖北省人民政府和教育部共建的地方高水平大学、湖北省'双一流'建设重点高校"。
- **关于"双一流"**：以上官方表述里**都没有**"国家'双一流'建设高校"这一说法。本次查证到的学校官网页面上，未发现学校声称进入国家级"双一流"名单。国家级"双一流"建设高校名单应以教育部公告为准，本文件不替官方下结论。

## 二、历史沿革（官网原文摘要）

| 时间 | 事件 |
| --- | --- |
| 1898 年 | 清末湖广总督张之洞奏请清政府批准成立"工艺学堂"，作为办学起点 |
| — | 历经湖北中等工业学堂、中南钢铁工业学校等传承与发展 |
| 1958 年 | 组建为武汉钢铁学院，开办本科教育 |
| 1995 年 | 原冶金工业部所属的武汉钢铁学院、武汉建筑高等专科学校、武汉冶金医学高等专科学校合并组建为**武汉冶金科技大学** |
| 1998 年 | 成为第一批"中央与地方共建，以湖北省人民政府管理为主"的划转院校 |
| 1999 年 | **更名为武汉科技大学** |

- 出处：<https://www.wust.edu.cn/xxgk.htm>、<https://xxgk.wust.edu.cn/info/1071/69992.htm>。
- 备注：官网"校史沿革"页 <https://www.wust.edu.cn/xxgk/xsyg.htm> 在 2026-10-13 实测时**正文为空**（只有导航和页脚），上表内容实际来自《学校简介》页。
