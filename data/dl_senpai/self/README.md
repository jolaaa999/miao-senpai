## 约定

- 后缀认 png / jpg / jpeg / webp；文件名带关键词才能被 `<<<SELFIMAGE 关键词>>>` 指定
- 几千像素的原图不用手动压：出站前自动归一化到 1280 长边、1.5MB 以内，
  压缩副本写在 `cache/` 子目录（**不会**混进素材池）
- 目录为空时，她会明确知道「我没有图」，并自然岔开话题，不会瞎编一张照片

配套开关：`DL_SENPAI_SELF_IMAGE_ENABLE`、`DL_SENPAI_SELF_IMAGE_DIR`、
`DL_SENPAI_SELF_CHARACTER`（填角色名可回落到生图用的已核验参考图）。
